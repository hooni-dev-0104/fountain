# 기능별 구현 상태

목표는 개인과 소수 가족이 별도 앱 구독료 없이 사용하는 독립 워크스페이스다. 플랜 선택·결제·인원 과금·문서 수 과금이 없다. Notion 유료 플랜의 전체 서버를 복제한 제품은 아니다. 아래는 실제 구현과 남은 작업을 구분한 목록이다.

| 영역 | 현재 동작 | 남은 차이 |
| --- | --- | --- |
| 문서 | 중첩 페이지, 여러 블록 유형, 자동 저장, 충돌 감지, 잠금·즐겨찾기·검색·휴지통 | CRDT 실시간 공동 편집, 완전한 리치 텍스트, 복잡한 중첩 블록 |
| 이력 | SQLite의 저장 버전 복원, 기한 제한 없음 | Notion과 같은 변경 비교 UI |
| DB | 속성, 행 편집, 필터·정렬, 테이블·보드·달력·갤러리·차트 | 타임라인, 복잡한 대시보드, 하위 작업·의존관계 UI |
| 계산 | 안전한 수식 AST, 관계 검증, 합·개수·평균·최솟값·최댓값 롤업, 오류 표시 | Notion 수식 언어 전체, 복잡한 함수 라이브러리 |
| 자동화 | 수동·행 생성·행 수정 트리거, 조건, 속성 변경·행/페이지 생성, 실패 시 롤백 | 예약 실행, 외부 액션·웹훅 전송 |
| 양식 | 질문·필수 값·조건부 표시, 응답 검증, DB 행 생성, 실제 공개 HTML | 파일 질문, 모든 Notion 스타일 옵션 |
| 사이트 | 실제 페이지 HTML, 게시/해제, 주소·SEO 제목·설명, XSS 이스케이프 | 외부 DNS·TLS·사용자 도메인 배포, Notion 호스팅 |
| 가족 접근 | 선택적 공용 비밀번호, 해시 세션, 7일 만료·로그아웃·시도 제한 | 개인별 계정·세밀한 가족 구성원 권한 |
| 멤버·팀스페이스 | 멤버·그룹·팀스페이스 정보 저장·관리 | 개인별 인증 및 페이지·행 접근 제어 |
| 검증 | 담당자·시각·만료일 검증 API | 검증 만료 알림 |
| AI | 실제 호환 API, 키 없는 무료 로컬 서버, 생성·요약·번역·질의·대화록 정리 | 로컬 모델 설치·다운로드, 음성 전사, 자율 에이전트·웹 리서치 |
| Gemini Pro | 공식 CLI 구독 연동 가능성 검토와 한도·API 과금 구분 | CLI 설치·로그인·격리 어댑터·실사용 검증 |
| 관리 | 실제 변경/조회/검색 이벤트 감사 로그·집계, 게스트/게시/내보내기 제한 | 외부 SIEM/DLP, 조직 분석, 관리자 역할 분리 |
| SCIM | Bearer 인증 Users/Groups CRUD·일부 PATCH·페이지 나누기 | SCIM 필터·전체 적합성·실제 IdP 검증 |
| 보존 | 휴지통·대화록 보존 설정과 정리 실행 API | 주기 실행기, 불변 감사 저장소 |
| 백업 | 댓글·이력·첨부·설정까지 전체 SQLite 백업·복원, JSON 페이지·DB·행/관계 복원, Markdown·CSV 가져오기·내보내기 | PDF 일괄 출력, 자동 예약 백업 |
| 첨부 | 문서에서 업로드·다운로드, 이력의 파일 참조 보호, 로컬 파일 5MB 한도 | 유료 플랜의 파일당 약 5GB 업로드·스트리밍 |
| 외부 연결 | 연결 정보와 SAML 메타데이터 설정 저장 | OAuth, SAML 서명 검증 로그인, 외부 앱 색인·동기화 |
| 오프라인 | 서버가 로컬 PC에 있어 인터넷 없이 기본 기능 사용 | 서버 없이 브라우저 단독 편집·동기화 |

`GET /api/capabilities`와 설정의 기능 제공 현황에도 상태를 표시한다. 멤버와 그룹 설정은 실제 다중 사용자 인증을 대체하지 않는다. 외부 LLM의 무보존 보증과 전담 지원은 로컬 코드만으로 제공할 수 없다.

## 검증 원칙

문서·행·설정은 실제 SQLite에 저장한다. 브라우저 테스트는 실제 로컬 HTTP 서버에서 편집·저장·복원과 화면 이동을 수행한다. AI 어댑터의 테스트 공급자는 테스트 전용 로컬 HTTP fixture이며 실제 모델 품질이나 구독 연결 성공의 증거가 아니다. REA 분석 범위는 [분석 기록](research/notion-rea.md)에 별도로 남겼다.
